## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Session Library** | Organize Logic Pro projects with artist, genre and status |
| **Plugin Manager** | Track installed Logic plugins with category and session usage |
| **Mix Notes** | Document mix decisions and plugin chain settings per project |
| **Version Control** | Track session versions with key production change notes |
